# 本轮验收说明

日期：2026-09-25。基于 `dev` 的 `9155915` 开发，本文记录本次 0.4.0 改动及本地验证结果。

## 已完成

- 五种布局：经典双行、紧凑、专注封面分栏、竖向多行、全屏居中。多行预设支持原文换行，当前歌词与译文组合居中，长句不会压住下一行。
- 设置采用左侧导航与中英文搜索、右侧页面；支持两种界面语言、字号、原文／高亮／背景颜色、透明度、毛玻璃、译文、Logo、播放器信息、锁定与模拟高亮。另有独立主题页，提供深色红／蓝、浅色红／蓝与可命名保存、更新、删除的自定义配色；切换配色不改布局和字号。应用按钮固定在页面底部。关于页包含作者 Lazy_V、从项目构建信息读取的 0.4.0 版本和仓库入口。
- 设置使用图标按钮；显示实际播放器名称；关闭歌词窗口收起到托盘。锁定仅固定窗口位置，缩放与其他控件仍可用，可从托盘、设置或 Ctrl+L 解锁。
- QQ、网易云、YesPlayMusic 的双语歌词经过时间对齐后显示。真实逐字歌词优先；可选的逐行模拟效果明确标注为模拟，不伪造词时间。
- 改善歌名、主艺人、录音版本与时长匹配；升级 Lyricify Helper 至 0.2.0；隔离各来源故障；拒绝晚到的旧曲结果。匹配和获取的详细结论见 [调研报告](./lyricify-research.md)。
- 可用队列的后续歌曲提前缓存，默认 5 首；当前曲优先，缓存可跨进程复用。接入 Cider API 队列及可选 MPRIS TrackList。
- 收藏按连接能力显示；当前适配 Cider V4。后台读取不触发忙碌状态，点击后等待播放器确认；GUI 连接 CLI 时通过 CLI 转发收藏请求。
- CLI／交互终端／GUI 共用认证配置，支持 token 和在 Cider 中主动关闭认证后的无 token 模式。设置不回填或显示已保存令牌，文档截图没有真实凭据。
- CLI、TUI、GUI 均复用现有服务；服务关闭后按 GUI → TUI → CLI 优先级接管，健康服务不会被抢占。保留可配置的本机／局域网服务监听与目标地址。
- 使用 .NET 10；中英文 README、Quickshell 集成说明与实际控件生成的截图均已更新。

## 建议验收顺序

1. 当前已运行 GUI，打开齿轮或托盘的“设置”，在“外观”依次选择五种预设并应用；全屏时按 Esc 返回专注预设。
2. 调整字号、颜色、透明度和毛玻璃并保存，确认立即生效；重启后确认保存值仍在。原文与译文字号可分别调整。主题在「主题与配色」选择；自定义配色先命名保存、再应用。
3. 搜索“字体”“翻译”“收藏”或 `Lazy_V`，检查导航和对应设置；切换 English 与简体中文，确认界面、托盘和搜索可用。
4. 在有译文的歌曲上检查双语开关；对 QRC／YRC 检查播放、暂停与跳转的高亮位置。普通 LRC 开启模拟后检查高亮推进；普通界面不再显示“逐字同步”角标。
5. 锁定窗口，确认无法拖动，但播放、收藏、设置和缩放仍可用；从托盘解锁。关闭歌词窗口后从托盘重新显示。
6. 在 Cider V4 检查收藏与取消收藏；图标应在读取到播放器确认后变化，悬浮或后台刷新不应自行改变收藏。其他未提供收藏能力的连接隐藏按钮。
7. 启动 CLI 后打开 GUI，确认复用服务；退出 CLI 后确认 GUI 接管服务；重新启动 CLI 后由 CLI 复用 GUI 服务。提供队列的播放器切换到已预取歌曲时应直接复用缓存。

预设与设置截图见 [中文用户指南](./user-guide.zh-CN.md#五种界面预设)。截图使用原创示例歌词和测试配置；真实播放器检查没有改动播放状态或收藏。

## 已知边界

- 尚未在 Windows、macOS 或 Cider V3 上进行本轮实机运行验收。
- 逐字歌词与译文依赖提供方；元数据匹配不能保证所有录音和时间轴正确。尚未加入人工曲目绑定、单曲候选选择与单曲偏移编辑，也没有 Lyricify 的私有云端校正库。
- Spotify Web API 队列和 macOS Apple Music 原生队列尚未适配；无队列时只缓存已请求的歌曲。
- 当前锁定不包含跨平台鼠标穿透；毛玻璃依赖系统支持。
- 收藏依赖播放器的专用能力。Cider 写入端点面向当前播放曲，客户端前后校验不能替代服务端的按曲目 ID 原子写入。

其余协议、认证方式、平台组合与测试运行方法见[英文指南](./user-guide.md)与[中文指南](./user-guide.zh-CN.md)。
