# OmniLyrics 0.4.0 界面设计

## 统一规则

- 8 px 间距网格；页面内边距 24–40 px，分组间距 16 px，设置行高度至少 64 px。
- 普通按钮高 36 px、文字双向居中，主操作最小宽 88 px；图标按钮 36×36 px，播放主按钮 44×44 px。
- 控件采用同一套圆角与中性色表面。主题色用于设置选中态、主操作与启用态；选中导航和主按钮使用亮色文字，并按需加深填充色以达到 4.5:1 对比度。歌词保留用户配置的高亮色。
- 标签和说明左对齐；按钮、数值、歌曲操作居中。歌词原文与译文整体居中，换行后每行仍居中。
- 设置表单控件按行右对齐，不将数值输入框、下拉选择或普通按钮拉满整行。

## 歌词窗口

- 右上角只保留设置、锁定、关闭。阅读模式的收藏、上一首、播放／暂停、下一首固定在歌曲信息区域下方。
- 宽窗口采用封面／歌曲信息与歌词双栏；封面尺寸、栏间距、歌词字号随实际内容区尺寸变化，不能只扩大空白。
- 窗口宽度小于 760 px 时，专注布局切为上方歌曲信息、下方歌词。竖向预设保持此结构；全屏歌词居中，歌曲与操作区置于左下。
- 经典和紧凑预设保留悬浮工具栏，适合桌面叠加。
- 所有控件及托盘不显示工具提示，保留无障碍名称。单双行窗口可拖动边缘调整大小，仅约束最小尺寸；切换配色不覆盖手动尺寸。切换预设时恢复对应窗口尺寸；退出全屏后等待系统恢复窗口，再应用新尺寸。
- 锁定只禁止拖动位置；缩放、播放、收藏、设置和解锁入口保持可用。
- 封面尺寸在为歌曲信息与操作按钮预留自然高度后计算；字体、曲名、缩放或窗口大小变化时重新测量，底部操作不得被裁切。
- 当前原文与译文按实际高度测量为一个组；上下文按顺序排在两侧，组间至少 32 px。空间不足时裁去远处上下文，不能相互覆盖。
- 不显示“逐字同步”状态角标。逐行歌词的模拟高亮默认开启，在设置中说明其为估算效果。

## 设置窗口

- 左侧固定导航：Logo／应用名、带图标的搜索、常规／外观／主题与配色／播放器连接／关于；高级菜单置底。
- 搜索输入区位于导航控件上层，点击搜索图标也能聚焦。导航整行可点击，搜索的延迟滚动不能作用于已经切走的页面。
- 右侧标题固定，表单在独立区域内滚动；底部应用／关闭固定。
- 滚动条占独立宽度，内容与轨道之间至少留 12 px，不盖住卡片边缘、下拉箭头或按钮。
- 表单用横向设置行组织相关项目，减少嵌套卡片与重复说明。颜色控件等紧凑项目按组排列。
- 关于页的 Logo、应用名、版本和作者居中，版本由项目构建信息读取。
- 普通界面不显示配置路径；高级配置编辑器提供文本编辑、校验、重新载入和应用。外部有效修改同步到设置与歌词窗口，无效编辑保留上一次有效值；编辑器保护尚未保存的草稿，避免覆盖外部修改。

## 验证尺寸与状态

- 歌词窗口：1040×580、1600×900、580×900；五种预设分别检查。
- 设置窗口：980×760 与最小 790×580；检查滚动条空间、底部动作、长中英文说明和搜索结果。
- 检查中英切换、长原文／译文、字体变更、窗口实际缩放、显示／隐藏译文与锁定。
- 系统语言切换检查下拉框实际显示内容；指针测试检查导航各位置的选中项与焦点。尺寸测试处理原生窗口事件，检查全屏实际尺寸及退出后的连续预设切换。
- 模拟播放器用于按钮与布局测试，真实播放器仅验证只读显示。

## 主题与配色

- 布局预设和配色预设独立。切换配色不改变字号、布局、锁定、透明度、毛玻璃和显示选项。
- 内置深色红、深色蓝、浅色蓝、浅色红。可单独指定深／浅界面、主题色、歌词文字色、高亮色和歌词背景色。
- 深浅界面覆盖歌词工具栏、歌曲信息、设置、编辑器及控件弹层；阅读布局使用无阴影字形，避免浅背景上出现黑色重边。
- 自定义配色可命名保存、再次选择、同名更新和删除。保存预设不立即应用配色；统一使用底部「应用」启用草稿。
- 最多 32 个自定义预设，名称限 1–64 字符；保存在共享 config.json 的 themePresets 数组，文件监听同步外部编辑。
